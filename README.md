# 小碎 AstrBot 插件 README

可爱的小机器人 **小碎** 🩵  
基于 **AstrBot 框架** 的 QQ 插件，集成互动、签到、运势、占卜、投喂、彩蛋与成就系统。  
代码风格清晰、结构统一，可直接放入 AstrBot 插件目录运行。

---

## ✨ 功能总览

### 🌞 日常互动
| 指令 | 功能 |
|------|------|
| `小碎` | 随机问候与颜文字回复 |
| `购买方式` | 带上发言者名字，提示查看群相册《上新预告》中的规则与开始时间 |
| `小碎表情包` | 从随插件附带的 8 张小碎表情包中随机回复一张原图 |
| `抽签 数字` | 随机返回 1～指定正整数中的一个整数，含两端；例如 `抽签 90` |
| `签到` | 每日一次，按时间段打招呼，显示每日基础运气，获得好感与玻璃珠 |
| `我还要签到` | 第二次签到，九段运势由每日基础运气决定，仅影响玻璃珠 |
| `占卜` | 按每日运气与小幅波动选取 22 张塔罗牌的正逆位，展示等级与情绪文案 |
| `投喂` | 3 分钟冷却，随机食物互动，有特殊投喂奖励 |
| `运势` | 受每日基础运气影响的当下百分制运势，仍可波动；0 → 安慰 +3珠；100 → 祝福 +10好感 +50珠 |

### 💎 新成员入口与表情包（v1.3.0）

发送 `购买方式`，小碎回复两行固定提示，名字使用当前消息中的发言者名称，不实际查询相册或办理交易：

```text
群友名字 请看群相册《上新预告》哦
具体规则和开始时间在对应图片界面有进行标注～
```

发送 `小碎表情包`，从插件根目录 `xiaosui_sticker_01.jpg` ～ `xiaosui_sticker_08.jpg` 等概率随机选择一张。每次只发一张图片，可连续随机到同一张，不主动推送，不附加文字，不调用 AI。图片保留用户提供的原文件内容，没有重新压缩或修改；仅复制为简单文件名。图片缺失时会提示管理员补齐。

两个指令沿用现有 AstrBot 指令触发设置，普通成员可用；不会新建用户记录、改变签到次数、运气、好感、玻璃珠或彩蛋，也不访问交易记录。消息发送方式参考 [AstrBot 官方文档](https://docs.astrbot.app/dev/star/guides/send-message.html)。

升级时备份当前插件与 `data/xiaosui_state.json`，替换三份源码/说明及八张图片；不要删除插件后重装，也不要用旧备份覆盖现有存档。

### 🍀 每日基础运气（v1.2.0）

每个用户在北京时间当天第一次使用上述任一指令时，随机生成 0～100 的基础运气。同一账号当天跨指令、跨群、重载插件都共享这一数值；北京时间零点后，下次使用时生成新值。不同用户分别生成数值，也可能恰好相同。

四条指令都显示 `🍀 今日基础运气：75%` 这样的提示。这个百分比是游戏里的运气分数，不代表实际中奖概率。

- `签到`：显示共享数值，原有 0～30 好感度和 0～30 玻璃珠奖励仍分别随机。
- `我还要签到`：按基础值给出固定九段日运势。0～11 大凶、12～22 凶、23～33 中凶、34～44 小凶、45～56 平、57～67 小吉、68～78 中吉、79～89 吉、90～100 大吉。
- `占卜`：在基础值附近 ±10 分内随机一次，依分数选择等级，再从该等级对应的牌面中随机抽取；保留牌面本身的正逆位、含义与奖励规则。等级区间：0～10 F、11～25 D、26～40 C、41～60 B、61～80 S、81～94 SS、95～100 SSS。
- `运势`：80% 在基础值附近 ±25 分内随机，20% 在完整 0～100 范围随机，保留当下的意外；不会改写当天基础值。每个区间都截在 0～100 内，0/100 原有特殊奖励继续生效。

仅新增用户字段 `daily_luck: {date, value}`。已有好感、玻璃珠、签到日期和收藏保留；升级当日已经签到或占卜的用户仍不能重复领取奖励。换一天后数值会重新随机，但有可能恰巧与前一天相同。

QQ 回复中的 Markdown 加粗星号已移除，彩蛋标题前的分隔星号改为 ✨；颜文字里的星号保留。

本版本通过离线回归测试，实际 AstrBot 加载与群内效果需在部署后验证。

### ★ 彩蛋系统

- 互动指令（签到 / 二签 / 占卜 / 投喂）：**20%** 掉落概率  
- 特别彩蛋（星露谷 / 饥荒 / 泰拉瑞亚）：**10%** 独立触发  
- 传说彩蛋（最稀有 `u00`）：**0.5%** 独立触发  
- 普通/稀有/超稀有概率权重：**82% / 17% / 1%**

彩蛋分为：
- 普通 25 个 → `NORMAL_EGGS`
- 稀有 10 个 → `RARE_EGGS`
- 超稀有 5 个（含传说）→ `ULTRA_EGGS`
- 特别 10 个（联动）→ `SPECIAL_EGGS`

所有彩蛋唯一，不会重复获取。

## 🧩 文件与数据结构

- **插件类名：** `MyPlugin(Star)`
- **注册名：** `helloworld`
- **数据文件：** `data/xiaosui_state.json`
- **存储内容：**
  - 用户状态（好感 / 玻璃珠 / 签到时间 / 投喂冷却）
  - 彩蛋与成就进度记录

---

## 🎲 概率机制

- 互动行为（签到 / 占卜 / 投喂 / 二签）→ 20%  
- 特别彩蛋 → 10% 独立判定  
- 传说彩蛋 → 0.5% 独立判定  
- 彩蛋权重分配：普通 82%、稀有 17%、超稀有 1%

每条消息与指令执行都会触发独立判定，无重叠概率冲突。
